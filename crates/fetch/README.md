# dalica-fetch

**Layer L1.** Consented, resumable, hash-pinned downloads (`docs/faces.md` §3.1, `docs/security.md` §8.2), over a transport the caller chooses.

- **May depend on:** L0 (`docs/architecture.md` §2; `cargo xtask layers` enforces it): `dalica-fs` for every write. External: `sha2` (RustCrypto, pure Rust), `thiserror`, and for the HTTPS transport `rustls` (default features off), `rustls-rustcrypto` and `webpki-roots`.
- **Public API (M13.8):**
  - `spec`: `FileSpec::new(url, name, cap, size, sha256)` → `FileSpec` or `SpecError`, checked before anything is fetched: an `https://` `Url` (no plain http, no user name or password, no spaces or control characters, at most 8 KiB), a local `name` that never comes from the address or the server (one plain, ordinary file name: no separator, drive, stream, Windows device or forbidden character, no leading dot, not `*.part`, at most 250 bytes), a `cap` of 1 byte to `MAX_CAP` (8 GiB), an optional pinned `size` (1 to the cap) and SHA-256 (64 hex digits, either case). `limit()` is the pinned size or the cap; `resumable()` is true with a pinned SHA-256. `Url::display()` leaves the query out (for messages).
  - `Consent::acknowledged(&spec, acknowledged)`: the user's acknowledgement of one file's terms; `false` is refused (`FetchError::NoConsent`). A `Consent` covers only its own spec and is neither `Clone` nor `Default`.
  - `transport`: `Transport::get(&Request, &Limits) -> Reply { status, length, content_range, body }`, `Body::read(buf, &Limits)`; `Limits { connect, stall, cancel }` (the transport keeps the timeouts and follows redirects itself, never from https to http); `Request` is made by `fetch` only: its address, the first byte wanted and `headers()` (a generic `USER_AGENT`, `Accept`, `Accept-Encoding: identity`, and `Range` for a resume; `HEADER_NAMES` lists every name sent). `MemoryTransport` (`serve(url, Served { bytes, status, ranges, announce, cut_after, chunk })`, `requests()`, `reads()`, `bytes()`) answers from memory for tests.
  - `download(&spec, &consent, dir, &dyn Transport, &Options, &cancel, &mut progress) -> Downloaded { path, size, sha256, resumed_from, fetched }`: bytes go to `<name>.part` beside the final place through `dalica-fs` (`PackFile`); a pinned part resumes with `Range`; a 200 to a resume starts over; a reply announced or read past the limit stops there and the part is deleted; the exact size and SHA-256 are checked before the part is moved into place (`transfer::move_file`, never replacing); a wrong size or hash deletes the file. A file already in place that matches the pins is kept with nothing requested; any other file of that name is refused (`FetchError::Exists`), never replaced. `Options { connect_timeout (15 s), stall_timeout (30 s), attempts (3, at most 16) }`: a broken connection, a stall, a 5xx or a 416 is tried again, resuming. Cancellation is checked before every read; a cancelled or broken pinned part is kept to resume, an unpinned one deleted. `Progress { done, total }` is reported as bytes arrive. `FetchError`'s messages say what happened to the file.
  - `TransportError` (`Connect`, `Stalled`, `Cancelled`, `Tls`, `Protocol`, `Refused`, `Io`) and `retryable()`: a stall, a broken connection or an answer that could not be understood is tried again (resuming); a refused redirect (`Refused`: to plain http, another scheme or an unusable address), a failed secure connection and a cancel are final.
- **Public API (M13.13, reserved decision 9):**
  - `HttpsTransport::new(proxy)`: the `Transport` over HTTP/1.1 and rustls with the pure-Rust RustCrypto provider (`rustls-rustcrypto`), trusting Mozilla's root certificates compiled in (`webpki-roots`); `HttpsTransport::with_roots(proxy, &[der])` trusts exactly the given roots instead (a local test server's), validation still on. One request per connection, exactly `Request::headers()` plus `Host` and `Connection: close`; `Content-Length`, chunked and read-to-close bodies; at most `http::MAX_REDIRECTS` (8) redirects, only to `https://` (`http::redirect_target`); heads capped at `http::MAX_HEAD` (64 KiB) and `http::MAX_HEADERS` (100); every wait wakes at least four times a second for the cancel flag. `http::read_reply(bytes, chunk)` reads a whole reply as the transport would (the fuzz target `response`).
  - `Proxy`: `direct()`, `manual(host, port)` (Options ▸ Network ▸ Proxy: manual), `system()` / `from_vars(var)` (`HTTPS_PROXY` / `https_proxy` and `NO_PROXY` / `no_proxy`: hosts, domains, addresses, ranges, `*`), `route(host)`; an HTTP proxy reached with `CONNECT` only, no proxy authentication (`ProxyError` says why a setting is unusable).
  - Its licence obligations: `webpki-roots` is `CDLA-Permissive-2.0` (the one reviewed licence exception, `security.md` §8.2); its text travels in `NOTICE`, which every release package ships.
- **Test it alone:** `cargo test -p dalica-fetch` (no window, GPU, network or personal photos needed). `tests/http.rs` against a TLS server on 127.0.0.1 with its own root: a cut download resumes with a `Range`, a truncated body fails, redirects are followed and capped and never to http (refused at once, never asked again), a stalled server times out and cancel stops the wait, oversized heads are refused, a proxy is used through `CONNECT` and skipped for `NO_PROXY` hosts, a certificate that does not validate fails. `tests/download.rs` over the in-memory transport: nothing requested or written without a consent (or with another file's); a download completes and verifies, and is kept without a request the next time; a cut download resumes from its `.part` (across runs and across attempts) and verifies; a wrong hash or announced size deletes the file and says so; a file of that name that is not the pinned one is never replaced; a reply past the cap stops one byte past it (unannounced) or before the body (announced); cancellation stops at the next read and keeps the pinned part; every request carries only `HEADER_NAMES` and the generic User-Agent; hostile specs are refused, and a property test feeds any URL, name, cap and pin without a panic. The integration tests are one binary (`tests/all.rs`, one module per file: `cargo test -p dalica-fetch --test all download::` runs one).

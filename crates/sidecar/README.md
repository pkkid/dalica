# dalica-sidecar

**Layer L1.** The `.dalica.json` folder sidecar: parse and print with unknown keys preserved; the read-only legacy reader and its conversion to Dalica's model.

- **May depend on:** L0 (`docs/architecture.md` §2; `cargo xtask layers` enforces it).
- **Public API:** none yet; this crate is a stub until M1.7 (`docs/roadmap.md`).
- **Test it alone:** `cargo test -p dalica-sidecar` (no window, GPU, network or personal photos needed).

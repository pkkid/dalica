# dalica-faces

**Layer L1.** Face detection, alignment, embeddings and clustering on decoded RGB buffers.

- **May depend on:** `core` (`docs/architecture.md` §2; `cargo xtask layers` enforces it).
- **Public API:** none yet; this crate is a stub until M29 (`docs/roadmap.md`).
- **Test it alone:** `cargo test -p dalica-faces` (no window, GPU, network or personal photos needed).

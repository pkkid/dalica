# dalica-create

**Layer L3.** Export (resize, quality, watermark, metadata copy), collage layout and render, slideshow sequencing.

- **May depend on:** L0–L2 (`docs/architecture.md` §2; `cargo xtask layers` enforces it). Uses `image` (decode, colour stage, resize, the M8.6 encoders), `edit` (the recipe and its CPU renderer), `meta` (metadata carried to a new file, M8.7). External: `moxcms` (the sRGB profile), `thiserror`. Tests also use `dalica-scenes`.
- **Public API (M8.10):**
  - `output::render(source bytes, &recipe, &Spec) -> Result<Output>`: the one output pipeline Save, Save a Copy, Save As and Export share (`architecture.md` §6, `data-model.md` §6). The source is read at full size under the decode limits (header checked before any decoder, the decoder panic-guarded), the recipe rendered at full size with the EXIF orientation applied (`edit::render`), fitted to `Spec::long_side` without ever enlarging (`image::resize::fit`), passed through the watermark hook, encoded (JPEG at `Quality::Match` = the source's estimate and chroma subsampling, else 90 and 4:4:4, or `Quality::Fixed(1–100)`, transparent pixels over white; PNG keeping transparency and 16 bits; grey stays grey while every pixel is neutral; an sRGB profile only when the source had one), then the source's EXIF, XMP and IPTC carried with orientation 1, the new size, an optional fresh 160-pixel EXIF thumbnail, GPS removed on request, and the caller's owned fields merged under its `WriteOptions`. A 16-bit grey or RGB PNG without a profile whose recipe only rotates and flips (no resize, no watermark) keeps its samples exactly; any other edit renders at 8 bits and is widened back to 16. Sources whose metadata `meta` does not read (GIF, BMP, HEIF, JPEG XL, PSD, non-TIFF raws) get only those facts and the owned fields (`Report::source_metadata`). Pure: bytes in, bytes out, nothing on disk.
  - `output::target(format, transparent, Purpose)`: `InPlace` (JPEG → JPEG, PNG without transparency → PNG, anything else `None`: the Save goes beside), `Beside` and `Copy` (JPEG), `Export` (PNG for transparency, else JPEG); `Choice::For(purpose)` or `Choice::Exactly(format)` (Save As).
  - `Spec` (`Spec::new(purpose)`: full size, Match, no thumbnail, watermark or owned fields), `Quality`, `Report` (format, size, bits, channels, quality and subsampling written, the source's estimate, profile, thumbnail, `source_metadata`, what was dropped), `Error` (`Spec`, `NotInPlace`, `Decode`, `Render`, `Encode`, `Metadata`, `OutOfMemory`, `Profile`; `reason()` is the text shown).
  - `watermark::draw(&mut Rgba8, text)`: the export watermark's hook; draws nothing until M8.11.
- **Test it alone:** `cargo test -p dalica-create` (no window, GPU, network or personal photos needed). `tests/output.rs` (helpers in `tests/common/`: scenes as JPEG, 8/16-bit PNG and alpha files, decoding, the `edit::render` oracle, PSNR, fingerprints): a q75 JPEG re-encoded at Match estimates at 75 ± 2 within 40 dB and a mean of 1 level; 4:2:0 kept; rotations give orientation 1 and the turned size; resizes hit the long side exactly and never enlarge; alpha and 16 bits kept (16-bit samples bit-exact when only moved); EXIF, XMP and IPTC carried with the owned fields and a thumbnail; GPS removed when asked; an sRGB profile only after a tagged source; a PNG output decodes to exactly `edit::render`, a JPEG one within 40 dB, both fingerprinted (`tests/fingerprints/output-*.json`; PNGs in `target/test-output/create/`, `DALICA_BLESS=1` rewrites them); undecodable, truncated and oversized sources and bad requests are `Err`; a 24 MP save is timed.

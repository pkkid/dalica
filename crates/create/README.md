# dalica-create

**Layer L3.** Export (resize, quality, watermark, metadata copy), collage layout and render, slideshow sequencing.

- **May depend on:** L0–L2 (`docs/architecture.md` §2; `cargo xtask layers` enforces it).
- **Public API:** none yet; this crate is a stub until M16 (`docs/roadmap.md`).
- **Test it alone:** `cargo test -p dalica-create` (no window, GPU, network or personal photos needed).

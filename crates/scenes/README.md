# dalica-scenes

**Layer L1.** Procedural test and demo photos (gradients, horizons, soft blobs, text-free patterns) at any size, depth and orientation, with a minimal EXIF block. No media files.

- **May depend on:** `core` (`docs/architecture.md` §2; `cargo xtask layers` enforces it).
- **Public API:** none yet; this crate is a stub until M1.4 (`docs/roadmap.md`).
- **Test it alone:** `cargo test -p dalica-scenes` (no window, GPU, network or personal photos needed).

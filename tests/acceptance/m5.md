# M5 manual check: first run on a fresh library, watching thumbnails fill in

`cargo xtask accept M5` checks the rest headlessly: the live app on a fresh library adding a folder
of every format (every file listed in order, twelve pictures shown, the HEIC, the AVIF and a damaged
JPEG each with a "!" and its reason in the tooltip, whole-window screenshots at both sizes matched
against `fingerprints/m5-*.json`); on a running session with a virtual clock, files and folders
added, removed, renamed, rewritten and moved outside Dalica reaching the library through the
watcher, the same found by the verification pass alone with the watcher off, a volume "unplugged" by
renaming its root shown dimmed offline with a star made meanwhile written when it returns, an emptied
mount point getting no sidecar; first run on a fresh library with the thumbnails filling in while
the scan runs; every format at each depth and profile compared with its scene, orientation 1–8 per
container, truncated and damaged files through every decoder entry point without a panic; the M5
crate suites; the first-thumbnails bench in a debug build; and the corpus floors when `corpus/` is
here and verified (it says so plainly when not). It prints where the two screenshots are
(`target/test-output/acceptance/m5-1400x900.png` and `m5-900x600.png`): look at them first, beside
`docs/formats.md` §1.

The time budgets need a release build, so they run only when asked for (the release build, then
about 10 minutes, most of it writing 111 000 test JPEGs, and some 4 GB of temporary files, removed
after):

```sh
DALICA_ACCEPT_RELEASE=1 cargo xtask accept M5
```

It adds `first_thumbnails` in full: the first screenful ≤ 1 s after adding 1 000 and 10 000 JPEGs,
with the full scan's time and photos per second, and the scanned 100 000-photo light table at the
speed thumb's top speed (no placeholder cell, owner time per frame p95 ≤ 8 ms). The `budgets` job
runs the same on every push to `main` with a 20 000-photo pass (`cargo xtask budgets`).

What only a person can judge is how it feels to start: the first-run panel, and the folders and
thumbnails arriving while the scan runs. This needs a display.

## 1. Photos to watch (optional)

Your own Pictures folder is the best test. To have something known instead (or as well), make
5 000 camera-sized JPEGs in 50 folders and the mixed-format folder, once, in a new folder of your
choice (an absolute path; about 20 s and 170 MB):

```sh
DALICA_M5_PHOTOS=/tmp/dalica-m5-photos cargo test --release -p dalica-acceptance --test m5 -- --ignored --exact make_the_manual_check_photos --nocapture
```

## 2. First run on a fresh library directory

1. Start the app on a library directory that does not exist yet:

   ```sh
   cargo run --release -p dalica -- --library /tmp/dalica-m5/library
   ```

2. The first-run panel (about 640 × 460) asks where your photos are. Try both choices:
   - **The standard places** (the default): Continue adds Pictures, Documents and Desktop as
     Scan Always. Folders appear in the tree while the scan runs, the activity indicator in the
     toolbar spins (a click lists the scan job with its progress and Cancel), and the status line
     reads "Scanning: 1,204 pictures found" until it ends.
   - **Choose folders…**: Continue opens the Folder Manager. Expand a place, set
     `/tmp/dalica-m5-photos` (or any folder) to Scan Always, and press OK.
3. Watch the thumbnails fill in: the screen you are looking at first (from the photos' embedded
   thumbnails where they have them), then the rest. Scroll while it runs: no cell stays grey for
   long, and the app stays responsive.
4. In the mixed-format folder: twelve pictures, then three tiles with a "!". Rest the pointer on
   each "!" for its reason (HEIC support isn't included in this build; AVIF files can't be
   displayed; Damaged file).

Quit, start the app again with the same command: no first-run panel this time, and the library
opens as you left it.

## 3. Also worth a minute

- Rename, move or delete a photo or a folder in your file manager while the app runs: the library
  follows within seconds, and a renamed folder keeps its stars.
- Rename a watched folder's root away (or unplug the card or drive it is on): within about ten
  seconds its tree rows are dimmed with an "offline" mark, its thumbnails stay. Star a photo in it,
  rename it back (or plug it in again): the star is in its `.dalica.json`.
- View → Use Color Management: the Display P3 photo (`Wide.jpg`) changes when it is switched.

Write what felt wrong on the M5.R check-in. Delete `/tmp/dalica-m5` and `/tmp/dalica-m5-photos`
when you are done.

# M2 manual check: an agent's screenshot of the real window matches your screen

`cargo xtask accept M2` checks everything else headlessly (a control session against
`dalica --headless` on a fresh demo, the screenshot's fingerprint, the security tests). This needs a
person and a display. Port 7990 is for this check only; automated runs never use it.

1. Start the app with its control channel on the demo library:

   ```sh
   cargo run -p dalica -- --control 7990 --demo
   ```

   The log in the terminal names the token file, e.g. `control: listening on 127.0.0.1:7990; token
   file /run/user/1000/dalica/control-7990.token` (on macOS `~/Library/Caches/Dalica/run/`, on Windows
   `%LOCALAPPDATA%\Dalica\cache\run\`). Only you can read it; it is removed when the app exits.
2. In the window, click a photo and press **Ctrl+8** (Cmd+8 on macOS), so the screen shows something
   the demo does not start with: a white outline and a star badge on that photo.
3. Ask your agent to connect to port 7990 with that token file and take a screenshot
   (`ui.screenshot`). Or do it yourself from a bash shell on Linux or macOS (the token is read by a
   shell builtin, so it never appears on a command line):

   ```sh
   TOKEN_FILE=/run/user/1000/dalica/control-7990.token   # the file the app printed
   d=${TMPDIR:-/tmp}; d=${d%/}
   exec 3<>/dev/tcp/127.0.0.1/7990
   printf '{"id":1,"method":"auth","params":{"token":"%s"}}\n' "$(head -n 1 "$TOKEN_FILE")" >&3
   printf '{"id":2,"method":"ui.screenshot","params":{"path":"%s/dalica-agent.png"}}\n' "$d" >&3
   head -n 2 <&3; exec 3>&-
   ```

   The second reply says `"ok":true`, the path, the size and `"headless":false` (it was read from
   the window, not drawn on the side).
4. Open the PNG (`$d/dalica-agent.png`) next to the window: the same folders, the same thumbnails
   in the same places, the outline and the star badge on the photo you starred, the status line
   ("1 of 60 pictures selected"). Its size is the window's in physical pixels (on a HiDPI screen,
   the window's size times the scale).
5. The app did not raise or focus its window to take the screenshot, and your typing in the
   terminal was never interrupted.
6. Close the window: the token file is gone.

Optional: minimise the window or cover it and take another screenshot. Today the window answers
`timeout` after about 2 s when it is not drawing; whether it should draw the image on the CPU instead
(`"headless":true`) is settled in M3.6. Press Ctrl+8 again to remove the star; the demo
is persistent, so a star left behind is still there next time.

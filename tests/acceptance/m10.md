# M10 manual checks: Options, shortcuts, MCP and the two checks on real hardware

`cargo xtask accept M10` checks the rest headlessly. The live app (`dalica --headless`, driven over
its control channel) on fresh libraries: every option the build can change set at once through
`options.set`, read back by `options.list`, kept across a restart with the keys of a later version
left in `settings.json` as they were, then every default back; Star rebound to F8 through
`app.setShortcut` and F8 pressed headless starring the selected photo while Ctrl+8 no longer does;
Ctrl+1 for Star refused naming Small Thumbnails in Library, then taken with `replace`; both keys
kept across a restart; Reset All in the shortcut editor restoring every row to its default. The
Options dialog's four tabs and the window at 150 % with Large text, matched against their
fingerprints. W02 and W01 through `dalica-cli mcp` over real stdio, in headless mode and in connect
mode against `dalica --headless --control`, checked on disk and agreeing. After that: M10's crate
suites, the workflow pass rate (`cargo xtask stats --check`, the nine P0 workflows), `cargo xtask
parity --p0`, `panic_hunt`, and the `scan_throughput` and `cold_start` benches in a debug build
(times printed). With `DALICA_ACCEPT_RELEASE=1` it also runs both in release and asserts the
budgets: 5 000 JPEGs scanned at 500 photos per second or more, the 100 k library's median cold
start within 2 s and its idle memory within 600 MiB.

It prints where the screenshots are: look at them first, beside `docs/design-system.md` §11.3 and
`docs/menus-and-shortcuts.md` §2.0 and §5 (all in `target/test-output/acceptance/`, at 1400 × 900):

- `m10-1400x900-options-general.png`: Options over the library, General selected among the four
  text tabs, Interface (animations, tooltips, system title bar with "Applies at next launch.", UI
  scale Auto, font size Small, Language drawn disabled) and Files; OK, Cancel and a disabled Apply;
- `m10-1400x900-options-file-types.png`: "Show JPEG files and:" with one checkbox per type, HEIC/HEIF
  disabled in a build without `heif`, the RAW row's list…, the small-picture threshold at 64 px;
- `m10-1400x900-options-export.png`: the default location (masked: a temporary path) with
  Browse…, Resize to and 1600 px on the slider with stops, quality Automatic, the custom quality
  disabled, remove location, the watermark text;
- `m10-1400x900-options-shortcuts.png`: the shortcut editor: search, Context: All, "Show commands
  without a shortcut", one row per command and context with its key cells, Reset All;
- `m10-1400x900-window-150-large.png`: the whole window at 150 % with Large text: everything
  larger, the bottom bar folded into More….

What only a person can judge needs a display. Work on a copy of a few folders of your own photos,
on a new library, in a release build:

```sh
cargo build --release -p dalica -p dalica-cli
target/release/dalica --library /tmp/dalica-m10/library
```

Add the copied folders (File ▸ Add Folder…) and wait for the thumbnails.

## 1. Options at 150 % and Large

1. Tools ▸ Options… (Ctrl+,; Dalica ▸ Preferences… on macOS). Change UI scale to 150 % and UI
   font size to Large: the window previews both at once. Cancel: both go back.
2. Again, then Apply: Apply greys out, the dialog stays open at the new size. OK closes it.
3. Use the app for a minute at this size: menus, the tree, the light table, the edit view
   (Ctrl+3). Nothing is cut off or overlaps; the text is sharp. Set Auto and Small again.

## 2. A File Types round trip

1. Make sure a folder holds a few PNGs; star one and caption another.
2. Options ▸ File Types: untick PNG, OK. The activity indicator says "Rescanning your folders…"
   and the PNGs leave the light table.
3. Tick PNG again, OK. The PNGs come back with their star and caption. Nothing was deleted or
   moved on disk.

## 3. Export defaults

Options ▸ Export: choose a location with Browse…, set 1200 px and Maximum quality, OK. Select a
few photos and click Export: the dialog starts from those settings.

## 4. A rebind with a conflict

1. Help ▸ Keyboard Shortcuts… (Ctrl+/). Search "star". Click Star's first key cell and press F8:
   the cell shows F8 and ↺ appears. Apply. Picture ▸ Star / Unstar now shows F8; select a photo
   and press F8: it is starred. Ctrl+8 does nothing.
2. Click Star's second key cell and press Ctrl+1: "Ctrl+1 is already Small Thumbnails in
   Library." with Replace and Cancel. Cancel keeps both as they were; do it again and Replace:
   Small Thumbnails has no key now. OK.
3. Ctrl+1 in the edit view still goes back to the library (another context, no conflict).

## 5. Reset All

Open the editor again: Reset All asks "Restore all default shortcuts?"; Reset All, then OK.
Star is Ctrl+8 again, Small Thumbnails Ctrl+1, and no ↺ is left. Quit and start again: the
defaults stay.

## 6. Dalica in Claude Code

```sh
claude mcp add dalica -- "$PWD/target/release/dalica-cli" mcp --demo
```

In Claude Code ask, for example: "Star the five most colourful photos of the demo library, make an
album of them called Highlights, caption two of them, crop one to a square, and export the album
at 1600 px into /tmp/dalica-m10/out." Check that it finds the tools by itself, that the files in
`/tmp/dalica-m10/out` are JPEGs with the long edge at 1600 px and the captions in their metadata
(`exiftool -Description` or any viewer), and that nothing outside the demo library and the output
folder changed. Remove it afterwards with `claude mcp remove dalica`.

## 7. Connect mode to a running app

```sh
target/release/dalica --control 7990 --library /tmp/dalica-m10/library
claude mcp add dalica-app -- "$PWD/target/release/dalica-cli" mcp --connect 127.0.0.1:7990
```

Ask Claude Code to select three photos in one folder and two in another, hold the first three,
and rotate the tray. Watch the window: the selection, the tray and the rotation appear there as
they happen, and Edit ▸ Undo in the window takes the rotation back in one step. Ask it to take a
screenshot: the picture it describes is the window you see. Quit the app while it is connected:
its next call says the app may have finished the operation and does not resend it; start the app
again and the next call works.

## 8. The Windows touchpad pinch (real hardware)

On a Windows laptop with a precision touchpad, open a photo in the edit view (Ctrl+3). Pinch out:
the photo zooms in about the fingers, smoothly, as Ctrl+wheel would; pinch in back to Fit. In the
library, a pinch changes nothing unexpected (Ctrl+wheel keeps the thumbnail size). Note the
laptop model in the check-in.

## 9. The macOS build used by hand

On a Mac, build and run (`cargo run --release -p dalica`). The menus live in the system menu bar
with Dalica ▸ Preferences… (⌘,) and Help ▸ Keyboard Shortcuts…; the window has the system's
traffic lights; shortcut labels show as glyphs (⇧⌘S) in the menus and the shortcut editor. Add a
folder, star, caption, edit and Save one photo, Export two, quit and start again: everything is
where you left it.

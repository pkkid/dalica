# M1 manual check: a star survives a restart in the real window

`cargo xtask accept M1` checks everything else headlessly. This needs a person and a display.

1. Start the app on the demo library:

   ```sh
   cargo run -p dalica -- --demo
   ```

   The demo library lives in `dalica-demo` in the OS temp folder and is reused between runs; delete
   that folder to start over with no stars. (`--demo-fresh` would not do for this check: its library
   is removed when the window closes.)

2. The window shows three folders on the left and their photos as thumbnails, newest folder first
   (`2026-06-06 Garden`, folder 1 to automation; its first photo is photo 1).
3. Click a photo: it gets a white outline and the status line says "1 of 60 pictures selected".
4. Press **Ctrl+8** (Cmd+8 on macOS): a star badge appears at the photo's bottom-right corner, and
   the star button in the bottom bar fills in.
5. Close the window, then run `cargo run -p dalica -- --demo` again.
6. The same photo still has its star badge.

Optional: press Ctrl+8 again to remove the star; File → Add Folder… opens the system folder dialog.

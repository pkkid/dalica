# M0 manual checks

`cargo xtask accept M0` has just shown that each gate fails on a planted violation and passes again
once it is removed (6/6). What a human should still look at:

1. **The empty window.** Run `cargo run -p dalica`. A window titled **Dalica** opens at 1400 × 900
   on the dark grey `chrome` colour, cannot be made smaller than 900 × 600, and closes cleanly
   (no panic message in the terminal).
2. **The CLI stubs.** `cargo run -p dalica-cli -- --version` and `cargo run -p dalica -- --version`
   print the workspace version; `cargo run -p dalica-cli -- commands` prints `[]`.
3. **The gate on a clean clone.** `git clone <repo> /tmp/dalica-check && cd /tmp/dalica-check &&
   cargo xtask ci` ends with every step `ok`.
4. **CI on three OSes.** The latest run of the `CI` workflow on GitHub is green on Linux, Windows
   and macOS.
5. **The board.** `cargo xtask tasks status` lists every M0 and M1 task with the status you expect.

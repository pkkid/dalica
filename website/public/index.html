What Dalíca writes to disk

Everything lives next to your photos.

Dalíca never copies your photos into a library of its own. What you add goes into one small, readable file per folder, and into the photos' own metadata.

  • Move a folder to another disk and its stars and tags go with it.
  • The index Dalíca keeps for speed is a cache. Delete it and Dalíca rebuilds it from your folders.
  • Originals are only ever moved aside when you Save an edit, never overwritten.

Add a tag in Dalíca and it is written into the photo itself, as XMP dc:subject and IPTC keywords, so any photo app that reads standard metadata sees it. Fields written by other programs are kept exactly as they were.

For scripts and AI agents

Everything is a command.

dalica-cli

The window and the command line share one engine.

Every action in Dalíca is a named command (98 of them today). Clicking, pressing a key and running dalica-cli all go through the same code, so whatever you can do by hand, a script can do too.

  • commands lists every command and its parameters as JSON.
  • run executes them against a library and answers in JSON.
  • snapshot renders the real window to a PNG without a display.
  • An MCP server for AI agents arrives with version 0.2.
terminal
$ dalica-cli commands | jq length
98
$ dalica-cli run --demo --cmd photo.star.set \
    --params '{"ids": [3], "on": true}'
{"command":"photo.star.set","ok":true,
 "result":{"ids":[3],"on":true}}
$ dalica-cli snapshot --demo -o library.png --size 1400x900

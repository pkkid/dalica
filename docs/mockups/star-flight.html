Dalica · the star's flight in the edit view Each card loops: rest, a click on the star button, the flight, a pause.

Rules every variant keeps

  • Never blocking. The star is written the moment the button, Ctrl+8, Space or Picture ▸ Star is used; the button fills at once. The flight is drawn over the window afterwards, takes no input and holds nothing back. Starring again mid-flight restarts it from the button (an unstar mid-flight ends the star's flight at once and plays the unstar's, if any).
  • Colour: the star is the star token (filled, as the star button's glyph when on) with a 1 pt crosshair_outer edge (black α160) so it reads over a white sky; the burst's ring is star at the opacity given. Nothing is hard-coded: a theme changes both.
  • Motion rule: design-system.md §1 says 80 ms animations, no bouncing, no long fades. A flight is an intentional exception: at most 500 ms, ease-out, no bounce, no overshoot. It needs the maintainer's OK and is written into design-system.md §8 as the one exception.
  • Use animations off (Options): no flight at all, only the state change (the button fills). The checkbox above shows it.
  • Which starring plays it: every user input in the edit view (the button, Ctrl+8, Space, the Picture menu). Never a star over the control channel, the CLI or MCP, so snapshots and fingerprints stay deterministic.
  • Where: the edit view only for now; the flight is one reusable piece (a start point, an end point, the clock) so the light table, the slideshow and the viewer could use it later.
  • Cost: nothing when idle (no repaint is asked for unless a flight is in the air); while one is, one star, one optional ring, about 60 repaints in 500 ms, well inside the 60 Hz frame budget.
  • Several photos: the edit view stars one photo; with photos held in the tray too the star button stars them all and still shows one flight.

Note on variant 2

editing.md §2 places a starred badge at the right end of the edit view's status line, but the status line does not draw it today. Variant 2 needs it drawn (a 12 pt star glyph after the line's last field, right-aligned), which touches the status line too; the page draws it where the spec puts it.
